# The Purple Door Universe

Fresh static rebuild for a second-grade review adventure site hosted on GitHub Pages.

## Current scaffold
- `index.html` polished landing page with three world doors
- `games/portalpark.html` first playable prototype
- `games/mathquest.html` and `games/wordquest.html` placeholder world entrances
- reusable CSS, save helper, question engine, and JSON data structure

## Asset plan
Store all downloaded assets locally in the `assets/` folders. Good first Kenney packs to add:
- UI Pack / UI Pack RPG Expansion for panels, buttons, badges, keys, and icons
- Platformer or Tiny Town assets for map nodes and scenery
- Board Game icons for gems, stars, cards, and collectibles
- Input Prompts only if you need navigation symbols

Avoid using remote image links. Keep license notes in an internal file later, not on student pages.
