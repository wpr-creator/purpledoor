# Game-Scene-First Homepage Update

This version rebuilds the homepage as a single controlled scene.

## Placement Guarantees

- The Purple Door is fixed in the center landmark zone.
- Word Quest is locked left of the door.
- Math Quest is locked right of the door.
- Wonder Trails is locked below the door.
- World labels sit below their buildings, not behind the door.
- Responsive rules resize and reposition nodes on smaller screens.

## Visual Direction

- Game scene first.
- World buildings are navigation.
- Purple Door is a landmark, not a giant blocking element.
- Monsters/companions are allowed, but used as small supporting characters.
- Background uses planets, stars, particles, and layered depth.
