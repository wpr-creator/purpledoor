# The Purple Door Universe — Art Direction Baseline

## Core direction
The homepage is a title screen, not the main game map. It should feel like a magical universe gateway: dark purple space, a single central Purple Door, and three clean world entrances.

## Asset use rules
- Use assets as supporting game pieces, not random decorations.
- Limit the homepage to a few strong props: stars, gems, compass icons, panels, and buttons.
- Avoid large cluttered maps on the homepage. Maps belong inside game worlds.
- Keep the Purple Door as the main focal point.
- Keep world cards below the door so nothing overlaps.

## Layout hierarchy
1. Title
2. Purple Door focal object
3. Three world choices
4. Small decorative rewards/icons

## World order
1. Word Quest
2. Math Quest
3. Wonder Trails

## Wonder Trails purpose
Wonder Trails is the broader second-grade review world for science, social studies, time, money, maps, weather, data, measurement, sequencing, and practical reasoning.

## 3D assets note
FBX files should stay out of the normal static homepage build for now. If 3D is ever used, convert models to GLB/glTF and load them through a small Three.js scene. For this project, render 3D models into PNG sprites when possible.
